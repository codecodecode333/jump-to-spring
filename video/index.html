01 · URL 설계
URL은 자원, 행위는 HTTP 메서드로
교재개선
GET /question/list→GET /questions
GET /question/detail/5→GET /questions/5
POST /answer/create/5→POST /questions/5/answers
POST /question/modify/5→PUT /questions/5
GET /question/delete/5→DELETE /questions/5
02 · 엔티티 설계
객체가 스스로 규칙을 지키게

BaseEntity

id · 생성일 · 수정일을 한 곳에, @CreatedDate로 자동 기록

Setter 제거

생성자와 modify()로만 상태 변경

LAZY 로딩

필요할 때만 조회해서 불필요한 조인 제거

addAnswer()

답변은 질문을 통해 생성, cascade로 저장

orphanRemoval

목록에서 빼면 DB에서도 삭제

equals / hashCode

프록시와 저장 전후에도 안전한 비교
