점프 투 스프링부트, 한 번쯤 따라 해 보셨죠?
저도 책대로 질문답변 게시판을 끝까지 만들고, 한 커밋씩 고쳐 나갔습니다.
오늘은 그중 일곱 가지를 보여 드립니다.
URL, 엔티티, N+1 문제, 보안, 테스트, 폼, 패키지 구조입니다.
각 장은 교재 방식, 문제점, 개선 코드, 결과 증명 순서로 갑니다.
범위는 교재 2장 컨트롤러부터 3장 검색까지입니다.
개선 아이디어는 장희성 강사님의 14163, 14168 강의에서 가져왔습니다.
환경은 Spring Boot 4.1.2, Java 25입니다.
교재는 Boot 3 기준이라 그대로 치면 막히는 곳도 있습니다.
교재 구현까지 커밋 서른여섯 개, 테스트 쉰일곱 개입니다.
커밋마다 무엇을, 왜, 어떻게 확인했는지 README에 남겼습니다.
