# 유튜브 업로드용 정보

## 제목
점프 투 스프링부트, 책대로 만들고 이렇게 고쳤습니다 | Spring Boot 4 리팩터링 7가지

## 설명란 (아래를 그대로 붙여 넣기)

점프 투 스프링부트의 질문답변 게시판(SBB)을 책대로 끝까지 만들고, 한 커밋씩 고쳐 나간 과정을 정리했습니다.
각 장은 ① 교재 방식 → ② 문제점 → ③ 개선 코드 → ④ 결과 증명(테스트·실제 화면·SQL 로그) 순서로 설명합니다.

0:00 인트로
0:34 프로젝트 소개
1:12 URL 설계
2:30 엔티티 설계
4:11 N+1 문제
5:30 보안
7:12 테스트
8:30 폼과 사용성
9:37 패키지 구조
10:10 마무리

## 챕터 시간표
`npm run build` 가 `build/chapters.txt` 로 만든다. 위 설명란의 시간과 같다.
유튜브는 첫 챕터가 `0:00` 이고, 챕터가 3개 이상이며 각 10초 이상이면 자동으로 챕터를 만든다.
