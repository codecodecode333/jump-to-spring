구멍 1
① 교재 방식② 문제점③ 개선 코드④ 결과 증명
상태를 바꾸는 GET 요청
question_detail.html (교재) — 삭제·추천
<a th:data-uri="@{|/question/delete/…|}"> … location.href = this.dataset.uri; // GET
SecurityConfig (교재) — 로그아웃
.logoutRequestMatcher( new AntPathRequestMatcher("/user/logout")) // 메서드 구분 없음 → GET 도 허용
다른 사이트에 숨겨 둔 한 줄
<img src="https://우리사이트/user/logout"> // 페이지를 열기만 해도 로그아웃
컨트롤러 (개선)
@DeleteMapping("/{id}") // 삭제 @PostMapping("/{id}/votes") // 추천
SecurityConfig (개선)
.logout(logout -> logout .logoutUrl("/users/logout")) // POST
<form th:action="…"> → <input type="hidden" name="_csrf" value="…"/> // 자동
PASSED CSRF 토큰 없이 POST 하면 403 (다른 사이트가 사용자 몰래 요청을 보내는 공격 차단)
구멍 2
① 교재 방식② 문제점③ 개선 코드④ 결과 증명
권한 없음은 400이 아니라 403
AnswerController (교재)
throw new ResponseStatusException( HttpStatus.BAD_REQUEST, "수정권한이 없습니다.");
400 = 요청 형식이 잘못됨
QuestionController (개선)
if (!question.isAuthor(user)) throw new ResponseStatusException( HttpStatus.FORBIDDEN, "권한이 없습니다.");
PASSED PUT /questions/{id}: 다른 사람의 질문은 수정할 수 없다 (403) PASSED DELETE /questions/{id}: 다른 사람의 질문은 삭제할 수 없다 (403) PASSED 다른 사람의 답변은 수정·삭제할 수 없다 (403)
구멍 3
① 교재 방식② 문제점③ 개선 코드④ 결과 증명
마크다운 XSS
CommonUtil (교재)
HtmlRenderer renderer = HtmlRenderer.builder().build();
본문의 HTML 이 그대로 → 글을 여는 모든 사람의 브라우저에서 실행
MarkdownService (개선)
HtmlRenderer.builder() .escapeHtml(true) // HTML → 글자 .sanitizeUrls(true) // javascript: 제거 .build();
같은 입력: <script>alert('xss')</script> · [클릭](javascript:alert(1))
<p><strong>질문입니다</strong></p> <script>alert('xss')</script> <p><a href="javascript:alert(1)">클릭</a></p>
교재 방식: 스크립트 그대로
<p><strong>질문입니다</strong></p> <p>&lt;script&gt;alert('xss')&lt;/script&gt;</p> <p><a rel="nofollow" href="">클릭</a></p>
개선 방식: 글자로 바뀜
